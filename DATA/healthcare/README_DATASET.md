# P-02 Synthetic Healthcare RAG Corpus

This corpus is synthetic and intended only for the P-02 hackathon demonstration.

## Demonstrated requirements

- Heterogeneous document ingestion: TXT, HTML, CSV
- Long/structured guideline-style content
- Table-heavy source: hospital_formulary.csv
- Conflicting guideline versions: v3 vs v4
- Versioning and supersession
- Role-based retrieval metadata
- Restricted synthetic document
- Insufficient-evidence/refusal cases
- Identifier-leakage security tests
- Payer policy, SOP, device manual and operational record

## Roles

- clinician
- nurse
- operations
- biomedical_engineer
- admin

## Important

All clinical statements are fictional. They must not be treated as medical guidance.
